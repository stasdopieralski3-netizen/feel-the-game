# Feel the game

A free desktop launcher for **Minecraft: Java Edition** with a clean, customizable frosted-glass design.

## Features
- Sign in with your own Microsoft account (official Microsoft login page)
- Every Minecraft version, with Fabric and Forge support
- Browse and install mods, resource packs and shaders from Modrinth
- Preview and change your skin and cape
- Built-in client features: zoom, free look, FPS/CPS counters, keystrokes, custom HUD
- Fully customizable colours and themes

## Privacy and security
- Login happens on Microsoft's own sign-in page; the launcher never sees your password.
- Login tokens are stored only in your operating system's secure keychain.
- No account data is collected or shared.
